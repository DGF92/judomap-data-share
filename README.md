# 주도맵 차트 개발용 가격 데이터

가음이에게 전달할 데이터 전용 비공개 저장소. 확인일: 2026-10-19, Asia/Seoul.

## 최종 목표
지수와 종목을 위아래에 놓고, 선택한 같은 시점에 세로선을 표시한다. 각 차트의 해당 시가 또는 종가에 가로선을 표시한다. 서로 다른 가격 단위를 억지로 맞추지 않는다. 수익률 비교는 각 기준값 대비 백분율로 계산한다.

## 이 저장소에 담긴 데이터
- 종목 005930·000660: 보유 일봉 전체와 보유 KRX 1분봉 전체를 담은 개발 샘플이다. 전체 종목 원본을 올린 저장소가 아니다.
- 코스피 KS11·코스닥 KQ11: 키움 출처 일봉. Yahoo 대체 출처와 중복 행은 제외했다.
- `preview/`: GitHub에서 바로 펼쳐볼 수 있는 1분봉 마지막 500행 CSV.
- `inventory/`: 실제 원본의 종목별 행 수와 시작·끝 시점. 목록에 있다는 뜻은 이 저장소에 해당 종목의 가격 파일까지 포함했다는 뜻이 아니다.
- 파일별 크기·SHA-256·기간은 `manifest.json`에 기록했다.

| 종류 | 원본 확인 범위 | 비고 |
|---|---|---|
| 일봉 | 3,080종목, 3,351,577행, 2021-07-20 ~ 2026-09-23 | SQLite 실제 조회 |
| KRX 1분봉 | 2,009종목, 140,451,231행, 2025-07-01 09:00:00 ~ 2026-09-04 15:35:00 | 실제 27,704개 Parquet 메타데이터 전수 확인 |
| 지수 일봉 | KS11·KQ11 각각 350행, 2025-04-01 ~ 2026-09-04 | KIWOOM_REST_INDEX, VALIDATED_OHLC |

이 범위는 저장된 가장 이른 값과 늦은 값이다. 모든 종목의 전체 거래일·거래분이 빠짐없이 있다는 인증이 아니다. 현재 확인으로 일봉 10년·분봉 5년 보유를 주장할 수 없다.

## 파일 형식과 사용법
- `data/daily/`: 종목별 CSV. 가격 단위 KRW, 거래량 주. 원본 `provider`와 `adjusted`를 보존했다.
- `data/intraday_1m/`: 종목별 Parquet와 동일 내용 CSV.gz. CSV.gz는 압축을 풀어 CSV로 읽으면 된다.
- `data/indices/`: 지수별 CSV. 가격 단위 지수 포인트. 지수 volume의 원 공급 단위는 별도 검증 전이므로 종목 거래량과 단순 비교하지 않는다.
- `security_code`는 앞자리 0을 유지하는 6자리 문자열이다. 원본 보유 목록의 일부 신규 코드는 영문자를 포함한다.
- `timestamp`는 한국 거래소 현지시각 Asia/Seoul이다. 원본에 없는 UTC 표시는 덧붙이지 않았다.
- 일봉은 `trade_date`, 1분봉은 `timestamp` 오름차순이다.
- 일봉의 수정주가 여부는 `adjusted` 기준이다. 분할·병합을 건넌 비교는 별도 검증이 필요하다.
- 거래정지 등 OHLC가 0인 행을 임의로 보정하거나 삭제하지 않았다. 표본의 검사 결과는 manifest의 `exported_sample_quality`를 참고한다.

## 현재 가능한 차트와 남은 항목
- 지수·종목 일봉 비교: 공통 날짜 2025-07-01 ~ 2026-09-04 안에서 먼저 개발할 수 있다.
- 종목 1분봉에서 5분봉을 만들 때 OHLC는 첫값·최댓값·최솟값·끝값, 거래량은 합계다. 장 시작·종료와 세션을 구분한다.
- 지수 분봉은 이 공유본에 없다. 지수와 종목의 분봉을 같은 시점에 비교하려면 지수 분봉을 추가로 확인해야 한다.
- 실시간 시세 공급, 자동 갱신, 미래 날짜 자료는 연결되어 있지 않다. 이 저장소는 고정 시점의 파일이다.
- 별도의 데이터 재배포·서비스 공개 이용 권한은 이 기술 점검에서 검증하지 않았다.

## 공유 범위
가격 데이터, 데이터 보유 범위, 이 설명서와 무결성 목록만 담았다. 기존 프로젝트의 코드·전략·사용자 판단·내부 문서·원본 DB·계정 정보·키·기존 Git 이력은 포함하지 않는다. 기존 저장소와 연결한 submodule도 없다. 비공개 저장소 접근은 초대한 GitHub 계정에만 부여한다.
